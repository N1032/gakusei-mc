ABOUT

サーバー概要

大学2年生（2026年7月現在）が企画・運営を手掛けるマルチ建築サーバーです。

一人ひとつのワールド

参加者全員にスーパーフラットのワールドが与えられます。アスレチックワールドや街作りなど自分の思うがままにワールドを作ることができます。

Java ＆ 統合版マルチプレイ

PC（Java Edition）、スマホ・タブレット・Windows（Bedrock Edition）のどちらからでも同じ空間に集まることが可能です。
Minecraft Java : 26.2
Minecraft Bedrock : v26.52
Bedrockは自動アップデートをOFFにしてください。アップデート配信直後はサーバーに参加できない場合があります。

HOW TO JOIN

初めての方はこちらから

自分のワールドはサーバー負荷軽減のため自動生成されません。以下の手順通りにワールドを作りましょう！

01

サーバーへ接続

アドレス m1032.duckdns.org（統合版ポート 19132）でサーバーに参加します。

02

ワールドを作成・移動

参加したら手元の草ブロックを右クリックします。（スマホの方は長押し）または素手で地面を２回左クリック（スマホの方は２回タップ）してワールドメニューを表示させてから、草ブロックを自分のインベントリに移動させてください。これらの操作を行うことで自分専用のワールドが生成されます。
/wo meまたは、エンダーパールを右クリック（スマホの方は長押し）することで自分のワールドへ移動します。

03

自分のワールドを建築しよう！

/wo gm 1 でクリエイティブ化。フレンドを呼ぶ場合は /wo invite プレイヤー名 で編集権限を付与します。
/wo sまた素手で地面を２回左クリック（スマホの方は２回タップ）して表示するワールドメニューからレッドストーンダストを選択すると、ワールド設定メニューを表示することができます。
